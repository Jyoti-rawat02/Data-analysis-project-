(Python GUI Calculator)
Project Overview
This project is a simple calculator built using Python and Tkinter.
It provides a graphical user interface (GUI) to perform basic arithmetic operations.

**Features**
Addition (+)
Subtraction (-)
Multiplication (*)
Division (/)
Clear screen (C)
Display result (=)
Technologies Used Python Tkinter Visual Studio Code GitHub

▶️ **How to Run**
Install Python
Open the file calculator.py
Run the program: python calculator.py
