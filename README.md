# Data Analysis Project (Excel)

## Project Overview
This project is based on sales data analysis using Microsoft Excel. 
The main objective of this project is to analyze sales data and create an interactive dashboard.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts
- Dashboard

## Work Done
- Data Cleaning
- Data Processing
- Data Analysis
- Dashboard Creation

## Insights
- Sales performance analysis
- Profit analysis
- Region-wise sales analysis

## Conclusion
This project helps to understand sales trends and business performance using Excel.
